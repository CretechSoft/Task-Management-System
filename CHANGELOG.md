# Changelog

All notable changes to the Task Management System will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Complete Flutter UI implementation with Material 3 design
- Multi-language support (English and Arabic) with RTL
- Login and authentication screens
- Dashboard with KPIs and quick actions
- Tasks list with filtering and search
- Task details with tabs (Details, Attachments, Comments)
- Task creation form with checklist support
- Projects management screen
- Departments management screen
- Employees directory
- Notifications center
- Settings screen with preferences
- Domain entities (Task, User, Project, Department)
- Navigation with GoRouter
- Theme system with light/dark mode support
- Utility classes for date/time, file handling, and validation
- Error handling framework
- Comprehensive documentation (API, State Machine, Testing, Deployment)
- Contributing guidelines

## [1.0.0] - TBD

### Initial Release
- Core task management functionality
- Role-based access control (Admin, TeamLead, Employee, QA)
- Task status workflow (Draft → Assigned → In Progress → Submitted → Approved/Rejected)
- File attachments support
- Comments and mentions
- SLA tracking and reminders
- Audit trail for all changes
- Offline-first architecture
- Push notifications
- Multi-platform support (iOS, Android, Web)
