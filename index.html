Node.js Express.js MongoDB Mongoose JWT Authentication Multer Node-Schedule bcrypt REST API

⚙️ إعداد المشروع / Setup Instructions

1. Install Dependencies

npm install

2. Configure Environment

cp .env.example .env # Edit .env with your MongoDB URI and JWT secret

3. Start MongoDB

mongod

4. Run the Server

# Development mode npm run dev # Production mode npm start

Server will run on: http://localhost:5000

📡 Main API Endpoints

POST /api/auth/register - Register new user
POST /api/auth/login - User login
GET /api/tasks - Get all tasks (with filtering)
POST /api/tasks - Create new task
GET /api/tasks/:id - Get task details (with attachments, comments, audit trail)
POST /api/tasks/:id/submit-review - Submit task for QA review
POST /api/tasks/:id/qa-review - Approve/Reject task
POST /api/attachments - Upload file attachment
POST /api/comments - Add comment to task
GET /api/notifications - Get user notifications
GET /api/tasks/metrics/performance - Get performance metrics
