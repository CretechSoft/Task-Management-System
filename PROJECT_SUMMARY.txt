PROJECT OVERVIEW
================================================================================
Complete enterprise-grade task management system built with Node.js, Express,
and MongoDB. Implements full lifecycle management from task assignment through
execution, quality assurance review, to final approval.

نظام إدارة مهام مؤسسي كامل مبني باستخدام Node.js و Express و MongoDB.
يطبق دورة حياة كاملة من إسناد المهام حتى التنفيذ والمراجعة والموافقة النهائية.

TECHNOLOGY STACK
================================================================================
- Backend: Node.js v14+, Express.js v5
- Database: MongoDB v4.4+
- Authentication: JWT (JSON Web Tokens)
- File Upload: Multer
- Scheduling: Node-schedule
- Security: bcrypt for password hashing
- Validation: express-validator

IMPLEMENTED FEATURES
================================================================================

1. USER MANAGEMENT
   - 4 user roles: Admin, Manager, QA, Employee
   - Department association
   - Role-based access control
   - User authentication with JWT
   - Password hashing with bcrypt

2. DEPARTMENT MANAGEMENT
   - Create/update/delete departments
   - Assign department managers
   - Custom color coding
   - Active/inactive status

3. PROJECT MANAGEMENT
   - Link projects to departments
   - Assign project managers and team members
   - Project status tracking (planning, active, on-hold, completed, cancelled)
   - Start and end dates
   - Custom colors

4. TASK MANAGEMENT
   - Complete lifecycle: Assignment → Execution → QA Review → Approval/Reject
   - Status: assigned, in-progress, pending-review, approved, rejected, completed
   - Priority: low, medium, high, urgent
   - Custom colors and tags
   - Due dates with SLA tracking
   - Task filtering and search
   - Pagination support

5. FILE ATTACHMENTS
   - Upload files/images (max 10MB)
   - Support for: images (jpg, png, gif), documents (pdf, doc, docx, xls, xlsx, txt), archives (zip, rar)
   - Attachment types: evidence, document, image, other
   - Download capability
   - File validation

6. COMMENTS & MENTIONS
   - Add comments to tasks
   - Mention users with @userId
   - Automatic notifications for mentions
   - Edit/delete own comments
   - Timeline integration

7. NOTIFICATIONS
   - 10 notification types
   - Read/unread status
   - Mark as read functionality
   - Automatic notifications for:
     * Task assignments
     * Status changes
     * Comments and mentions
     * QA decisions
     * Due date reminders
     * Overdue tasks

8. AUDIT TRAIL
   - Complete history of all changes
   - Track: user, action, timestamp, IP address
   - Previous and new values stored
   - Actions logged: creation, updates, status changes, assignments, comments, attachments

9. PERFORMANCE METRICS
   - Total tasks count
   - Completion rate
   - On-time completion rate
   - Overdue tasks count
   - Filter by user, department, date range

10. AUTOMATED FEATURES
    - Hourly reminder job (tasks due within 24h)
    - Overdue task detection
    - Automatic SLA compliance calculation
    - Auto-generated audit logs
    - Notification system

TASK LIFECYCLE WORKFLOW
================================================================================
1. ASSIGNMENT (إسناد)
   - Manager creates task
   - Assigns to employee
   - Status: assigned

2. EXECUTION (تنفيذ)
   - Employee starts work
   - Status: in-progress
   - Uploads evidence/files

3. SUBMIT FOR REVIEW (إرسال للمراجعة)
   - Employee submits completed work
   - Status: pending-review
   - QA reviewer notified

4. QA REVIEW (فحص الجودة)
   - QA examines evidence
   - Reviews completion

5. DECISION (القرار)
   a. APPROVE (إقرار)
      - Status: approved
      - Task completed
      - Metrics updated
   
   b. REJECT (رفض)
      - Status: rejected
      - Back to in-progress
      - Employee must address comments
